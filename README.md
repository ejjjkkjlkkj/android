# AccessibleAndroid — rebuild from zero

This branch is intentionally rebuilt from a minimal clean tree.

Goal: build an accessible Android 17 x86_64 system from scratch, with screen-reader-first boot, offline TTS, reproducible builds, clean validation, and final BIOS/UEFI VM images.

No files from the previous Android implementation are imported automatically. Components will be reintroduced only after audit and validation.
